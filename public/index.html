📘 啟用說明

1選擇主專案 必填

把專案資料夾拖曳到這裡

或

會自動略過 node_modules、.git、dist 等資料夾與二進位檔，檔案只在本機讀取。

2AI API Key 管理 必填

支援 OpenAI、Anthropic。Key 寫入專案根目錄的 config.js（不會存進瀏覽器 localStorage），由本機伺服器轉送給 AI 供應商。

進階設定（選填）

3分離範圍 必填

「切割 API 專案」與「建立 SKILL 架構」都會依此選項調整產出內容。預設只分離後端。

4想切割的部分 選填

可上傳截圖或用文字說明哪些功能要變成後端 API；都不填就由 AI 自行分析。

拖曳截圖到這裡、直接 Ctrl/⌘ + V 貼上，或
